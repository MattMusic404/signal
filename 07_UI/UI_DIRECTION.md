# UI visual direction
Main menu: dark, nearly empty pine forest; multiple visible depth layers of trees; ~60% heavier smoke than initial concepts; faint distant red drones and sweeping searchlights; interactive menu should be built separately from the background plate.
Pause menu: dark electronic, system-suspended atmosphere; worldbuilding through network telemetry, static and surveillance motifs. Republic blue and Aurelia violet can gradually appear as story progresses.
Proposed later interfaces: inventory, journal, intel archive, ability upgrades, Republic network map.
Concept images are not final editable UI source files.
